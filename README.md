🔍 Advanced Network Sniffer Tool (Python + Scapy + GUI)

A professional-grade network packet sniffer built using **Python, Scapy, Tkinter, and Matplotlib.  
Includes:

✔ GUI packet viewer .
✔ Real-time traffic chart .
✔ Protocol-based color coding. 
✔ Live protocol counters.
✔ CLI sniffer with color output.
✔ PCAP saving support.

---
🚀 Features

🖥️ GUI Sniffer
- Live packet capture.
- Color-coded protocol rows.
- Real-time traffic graph.
- TCP/UDP/ICMP counters.
- Start/Stop controls.

🧪 CLI Sniffer
- Color-coded output  
- Supports BPF filters  
- Saves packets to PCAP  
- Protocol identification
